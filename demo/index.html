Merkle proof verifier

This page loads the Rust verifiers compiled to WebAssembly. It does not hash in JavaScript. Build the module first (see demo/README.md), then paste output from the merkle CLI.

SHA-256 inclusion

From merkle prove --index N leaf…: put the original leaf in the first box (UTF-8, same as the CLI), the steps= list in the second, and the root= hex in the third.

Merkle-sum inclusion

Paste the key=value file from merkle sum-prove. The published root and total must come from the exchange, not from that file.

Merkle-sum non-inclusion

Paste the key=value file from merkle sum-absent. The published root and total must come from the exchange, not from that file. A pass means that account id is not among the leaves.

64-bit range proof

Optional. Rebuild with --features wasm,zk-range to enable. Amount is public; the proof only shows it fits in 64 bits.
